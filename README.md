# 🎯 Quiz Game Application

## 📌 Project Overview
This project is an interactive **Quiz Game Application** developed as part of my Web Development Internship. It allows users to answer multiple-choice questions, including single-select, multi-select, and fill-in-the-blank types, and displays the final score at the end.

The application focuses on interactivity, clean UI design, and simple logic implementation using HTML, CSS, and JavaScript.

---

## 🚀 Features
- Interactive multiple-choice quiz system  
- Supports single-select, multi-select, and fill-in-the-blank questions  
- Real-time answer evaluation  
- Final score display at the end  
- Clean and responsive UI design  
- Simple and user-friendly interface  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript
